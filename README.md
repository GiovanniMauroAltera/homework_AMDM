# homework_AMDM

Homework 1 for the course *Algorithmic Methods of Data Mining*.

The homework is about learning Python with the exercises on [HackerRank](https://www.hackerrank.com).

## What is in this repository

- `scripts.py`: the Python code of the exercises I solved. Each exercise is a function, and a comment above it gives the exercise name.
- `printouts/`: the PDF with my HackerRank submissions.
- `README.md`: this file.

## Problem 1: Python challenges

I solved exercises from these HackerRank sections:

- Introduction
- Basic Data Types
- Strings
- Sets
- Collections
- Date and Time
- Built-Ins
- Python Functionals
- Regex and Parsing
- XML
- Closures and Decorators
- Numpy
